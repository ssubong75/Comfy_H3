노드 이름: 화면 비율 · 해상도
노드 분류: ssubong/해상도

설치: ComfyUI-Resolution-Presets 폴더를 ComfyUI/custom_nodes 아래에 넣고 ComfyUI를 재시작합니다.
화면 비율을 먼저 고르면, 아래 해상도 단계에는 해당 비율의 전체 해상도와 MP 세 항목만 표시됩니다.
출력은 가로(INT), 세로(INT)입니다.
ComfyUI 내장 DynamicCombo를 사용합니다. 별도 JavaScript나 추가 패키지는 필요하지 않습니다.

16:9: 1536×864 / 1728×960 / 1920×1088
9:16: 864×1536 / 960×1728 / 1088×1920
2:3: 832×1248 / 1024×1536 / 1152×1728
3:2: 1248×832 / 1536×1024 / 1728×1152
1:1: 960×960 / 1280×1280 / 1440×1440
21:9: 1568×672 / 1792×768 / 2240×960

워크플로 적용용 노드:
- 화면 비율 · 해상도 · 생성 개수 (Qwen)
- 화면 비율 · 해상도 · 요청 길이 (H3)

바탕화면의 Qwen-Rapid-1.0-GGUF.json 및 H3-VDN-V3.json은 위 노드가 적용되어 있습니다.
해당 ComfyUI에 이 노드팩이 설치되어 있어야 사용할 수 있습니다.

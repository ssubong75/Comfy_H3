# Comfy_H3

ComfyUI custom node pack (`ssubong75/Comfy_H3`) for aspect-ratio / resolution presets and MOSS-Image / MOSS-Image-Edit speed mode switching.

## Included Nodes

- `SsubongResolutionPreset` (`화면 비율 · 해상도 선택`)
- `SsubongQwenResolutionPreset` (`Qwen · 화면 비율 · 해상도 · 초`)
- `SsubongH3ResolutionPreset` (`H3 · 화면 비율 · 해상도 · 초`)
- `SsubongH3CourseResolutionPreset` (`화면 비율 · 코스별 해상도 (1·2·3코스)`)
- `SsubongMossImageInput` (`MOSS · 비율 · 해상도 · 편집 강도`)
- `SsubongMossSpeedMode` (`MOSS · 50스텝 / 8스텝(DMD) 모드 선택`)
